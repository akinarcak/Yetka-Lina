# Yetka Lina

Yetka'nın web yönetim arayüzüdür. GPL-3.0-or-later lisansı ile dağıtılır ve Vue/Element UI kullanır.

## Geliştirme

```shell
npm install
npm run start
npm run-script build
```

API adresini `VUE_APP_CORE_HOST` ile yapılandırabilirsiniz.
